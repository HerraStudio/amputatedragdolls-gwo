Guns Workshop Origins content packs

Put folder, .zip, or signed encrypted .gwopack content packs in this folder.
A .zip pack must contain pack.mcmeta, weapons, bullets, and assets at its root.
A .gwopack must be created with the official gwopack-tool.
Firearm definitions live in weapons/firearms/*.json.
Melee weapon definitions live in weapons/melee/*.json.
Ammunition definitions live in bullets/*.json.
Gameplay, model, texture, animation, and display settings can live in one gun JSON file.
pack.mcmeta is generated automatically when missing.
